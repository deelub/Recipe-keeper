Recipe Keeper
Overview

Recipe Keeper is a Flutter-based mobile application developed as part of a Mobile Development elective project. The application allows users to store, manage, and organize their favorite recipes in a secure and user-friendly environment. Users can create an account, log in, save recipes, and receive recipe suggestions directly within the application.

This project demonstrates the integration of Flutter for cross-platform mobile development and Firebase services for authentication and cloud-based data storage.

Application Workflow
Users create an account or log into an existing account.
User credentials are authenticated through Firebase Authentication.
Verified users gain access to the application.
Users can add, view, update, and delete recipes.
Recipe information is stored securely in Firebase Firestore.
The application provides recipe suggestions to enhance the user experience.
